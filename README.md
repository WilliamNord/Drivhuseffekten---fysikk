# Drivhuseffekten

Et program som regner ut gjennomsnittstemperaturen på jorda med og uten atmosfære.


## Utvikling / Testing

for å teste programmet lokalt, må du først laste ned eller klone dette repositoriet:
```bash
git clone https://github.com/WilliamNord/Drivhuseffekten---fysikk.git
cd Drivhuseffekten---fysikk
```
Installer så Flask:
```bash
pip install flask
```
Etter det kan du starte programmet med:
```bash
# For MacOS/Linux:
python3 app.py

# For Windows:
python app.py
```
Programmet vil da kjøre her: http://127.0.0.1:5005/
